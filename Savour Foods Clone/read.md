# 🍽️ Savour Foods – Food Ordering Website

A modern, responsive, and user-friendly food ordering website inspired by popular Pakistani food delivery and restaurant websites.

This project is built using **HTML5, CSS3, JavaScript, and Bootstrap 5** with a focus on attractive UI/UX, responsiveness, and interactive functionality.

> **Note:** This is a frontend demo project created for educational and portfolio purposes. It is not affiliated with or an official website of Savour Foods.

---

## 📌 Features

### 🏠 Home Page
- Attractive hero section
- Food search functionality
- Call-to-action buttons
- Responsive navigation bar
- Popular food categories
- Featured food items
- Promotional sections

### 🍔 Food Menu
- Food cards with images
- Food names and descriptions
- Prices
- Add to Cart functionality
- Add to Favorites functionality
- Category filtering
- Search functionality

### 🛒 Shopping Cart
- Add food items to cart
- Increase/decrease quantity
- Remove items
- Automatic subtotal calculation
- Delivery fee calculation
- Grand total calculation
- Empty cart handling
- Cart item counter

### ❤️ Favorites
- Add/remove favorite food items
- Favorites stored using Local Storage
- Favorite counter
- Easy access to saved items

### 💳 Checkout
- Customer information form
- Name
- Phone number
- Email
- Address
- City
- Payment method
- Order summary
- Promo code support
- Order confirmation

### 🔐 Authentication UI
- Login modal
- Sign-up modal
- User-friendly forms
- Frontend validation

### 📍 Location
- Location selection
- Delivery location display
- Location-based UI interaction

### 🌙 Dark Mode
- Light/Dark theme toggle
- Theme preference saved in Local Storage

### 🔔 Notifications
- Bootstrap toast notifications
- Add-to-cart notifications
- Favorite notifications
- Order confirmation notifications
- Promo code notifications

### 📱 Responsive Design
The website works across:

- Desktop
- Laptop
- Tablet
- Mobile
- Small mobile screens

### 💾 Local Storage
The project uses browser Local Storage for:

- Cart items
- Favorites
- Theme preference
- User preferences
